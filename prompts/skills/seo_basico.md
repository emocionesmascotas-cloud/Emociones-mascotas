# 📊 Skill: SEO Básico

> **Skill:** Optimización para Motores de Búsqueda  
> **Nivel:** Básico  
> **Última actualización:** 2024-01-15

---

## 🎯 Objetivo

Este skill enseña técnicas básicas de SEO para que el contenido creado sea más fácil de encontrar en Google y otros buscadores.

---

## 📚 Fundamentos

### Cómo funciona el SEO
1. **Google lee** el contenido de la página
2. **Analiza** palabras clave y contexto
3. **Evalúa** calidad y relevancia
4. **Ranking** según algoritmo

### Factores importantes
| Factor | Peso | Descripción |
|--------|------|-------------|
| Keywords en título | 🔴 Alto | Keyword principal debe estar al inicio |
| Contenido original | 🔴 Alto | No copiar de otros |
| Keywords naturales | 🟡 Medio | No keyword stuffing |
| Meta description | 🟡 Medio | Aparece en resultados |
| Links internos | 🟢 Bajo | Conectar páginas relacionadas |

---

## 🔑 Keyword Research

### Cómo encontrar keywords
1. Piensa como tu usuario
2. Usa preguntas comunes
3. Busca en Google suggestions
4. Analiza competencia

### Tipos de keywords
| Tipo | Ejemplo | Uso |
|------|---------|-----|
| **Short-tail** | "mascotas" | Difícil ranking, mucho tráfico |
| **Long-tail** | "cómo registrar emociones de mi perro" | Más fácil, más específico |
| **LSi** | Sinónimos y variaciones | Contenido natural |

### Para Emociones Mascotas
```
Keywords principales:
- emociones mascotas
- registrar mascota
- cómo está mi perro
- bienestar animal
- emociones de gatos

Long-tail:
- cómo saber si mi perro está triste
- registrar estado emocional de mi mascota
- mejor app para mascotas
```

## ✍️ Optimización de Contenido

### Estructura HTML
```html
<!-- Título: máximo 60 caracteres -->
<title>Registrar Emociones de Mascotas | Emociones Mascotas</title>

<!-- Meta description: 150-160 caracteres -->
<meta name="description" content="Aprende cómo registrar y entender las emociones de tu mascota. 
App gratuita para dueños responsables.">

<!-- Encabezados -->
<h1>Cómo Registrar Emociones de Tu Mascota</h1>
<h2>¿Por qué es importante?</h2>
<h2>Pasos para comenzar</h2>
```

### Densidad de keywords
```
✅ CORRECTO: Mención natural 2-3 veces
"El registro de emociones de mascotas nos ayuda a entender mejor a nuestros 
compañeros. Cuando registramos las emociones..."

❌ INCORRECTO: Keyword stuffing
"Registrar emociones mascotas mascotas emociones registrar es importante para 
mascotas. El registro de mascotas y emociones..."

❌ INCORRECTO: Muy pocas menciones
"Aprende sobre el bienestar animal y cómo cuidar a tu compañero."
```

## 📱 SEO para Redes Sociales

### Twitter/X
```
Best practices:
- Keywords al inicio del tweet
- Hashtags al final (máx 2-3)
- URL acortada si es posible
- Emoji para destacar

Ejemplo:
"¿Sabías que puedes mejorar la vida de tu perro registrando sus emociones? 
Descubre cómo 👉 https://bit.ly/xxx 
#MascotasFelices #EmocionesAnimales"
```

### Instagram
```
Best practices:
- Keywords en caption (no bio)
- Hashtags relevantes (máx 10-15)
- Frase-hook en primeras líneas
- CTA claro

Ejemplo:
"🐕 Tu perro te dice más de lo que crees...\n\n
(sigue en comments) 👇\n\n
#Perros #EmocionesCaninas #DueñosResponsables"
```

## 📊 Checklist de SEO

### Antes de publicar
```markdown
□ Keyword principal identificado
□ Keyword en título (primera posición)
□ Keyword en primer párrafo
□ Keyword en al menos 1 subtítulo
□ Meta description escrita (150-160 chars)
□ Contenido mínimo 300 palabras
□ Sin keyword stuffing
□ Links relevantes incluidos
□ Imágenes con alt text
```

### Post en redes
```markdown
□ Keyword/hashtag relevante
□ Enganche en primeras líneas
□ Contenido valioso
□ Call to action claro
□ Hashtags correctos (máx número según plataforma)
```

## 🚫 Errores Comunes

| Error | Solución |
|-------|----------|
| Keyword stuffing | Escribir naturalmente, máx 2-3% |
| Títulos largos | Máx 60 caracteres |
| Sin meta description | Siempre escribir una |
| Contenido duplicado | Ser original siempre |
| Ignorar mobile | Diseño responsive |
